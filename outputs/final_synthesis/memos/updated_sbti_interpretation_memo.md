# Updated SBTi Interpretation Memo

## Most Important Post-June-2025 Changes

The updated SBTi context matters most through seven channels:

1. Corporate Net-Zero Standard V2 remains forward-looking and should not be retroactively imposed on 2012-2024 targets.
2. The 2026 Absolute Contraction Approach update affects future ambition comparability, not the validity of historical targets.
3. The Financial Institutions Net-Zero Standard creates a structurally distinct architecture for finance firms.
4. FLAG Guidance changes make land-intensive firms more rule-regime specific.
5. Automotive and land-transport changes make automotive firms a caution group.
6. Scope 3 treatment is now richer than a standalone absolute-target indicator.
7. Target status and review cycles make validation part of a lifecycle rather than a one-time credibility endpoint.

## What Affects Historical Interpretation

These changes affect how historical results should be described. They justify caveats around sector comparability, finance-sector pooling, Scope 3 taxonomy, ambition comparability, and the meaning of validation.

They do not require changing historical event dates, legacy ambition variables, or the legacy Scope 3 definition.

## What Affects Future Research

Future work should build method-aware ambition metrics, distinguish finance/FLAG/automotive pathways, incorporate current and historical target status, and separate first validation from renewal or revalidation cycles.

## What Creates Robustness Flags

The Phase 3 overlay creates flags for:

- current financial institutions;
- FLAG-relevant sectors and observed no-deforestation/timber proxies;
- automotive sector and automakers-pathway reason fields;
- oil and gas, power/utilities, chemicals, buildings/real estate;
- current near-term and net-zero statuses;
- richer Scope 3 target types.

These flags are appropriate for Phase 4/4B sensitivity checks, not for redefining historical treatment.

## What Should Not Be Applied Retroactively

Do not retroactively apply:

- Corporate Net-Zero Standard V2 draft logic;
- 2026 ACA ambition updates;
- current target-removal or expired statuses;
- current net-zero status;
- current Scope 3 target-type breadth;
- finance/FLAG/automotive standards as if they governed all historical targets.

## How To Use Current By-Company And By-Target Sheets

Use the by-company file as current company-level dashboard state. Use the by-target file as current target/commitment-row metadata. Treat `action == Target` as target rows and `action == Commitment` as commitment rows. Treat status fields as current dashboard metadata, especially for commitment rows. Do not use current status to reconstruct historical treatment unless historical tracker snapshots are available.
