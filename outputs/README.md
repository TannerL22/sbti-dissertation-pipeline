# Outputs Directory

This clean publication package includes selected lightweight result summaries only.

Full local generated outputs are intentionally omitted because they are large and may contain derived data artifacts.

Included summaries are enough to understand:

- what the legacy/refactored comparison found;
- what the clean statistical diagnostics changed;
- what the current SBTi overlay contributed;
- what robustness checks showed;
- how the dissertation conclusions should be updated.
